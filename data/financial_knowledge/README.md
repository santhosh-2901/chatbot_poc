# Financial knowledge base

Phase 3 populates this directory. Planned documents (spec section 11):

- `budgeting.md` — the 50/30/20 rule, zero-based budgeting, envelope method
- `saving.md` — savings rate, paying yourself first
- `emergency_fund.md` — purpose, sizing, where to hold it
- `credit.md` — credit utilisation, credit scores, repayment behaviour
- `loans.md` — secured vs unsecured, interest types, EMI mechanics
- `investing_basics.md` — compound interest, risk, diversification

These are chunked, embedded and indexed into FAISS for the RAG tool.

**Scope rule:** general financial education only. Nothing user-specific goes in
here — the user's own numbers always come from the transaction tools, never from
retrieval.
